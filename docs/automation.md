# Automation

For ordinary rule setup, follow [Automation rules](user-guide/Automation.md). Start with live automation unchecked, simulate below and at the threshold, then review filters, permissions, queue policy and the actual audio path before enabling it.

Rules consume accepted live canonical events. Conditions use native minor currency units or quantities; a nominal USD ledger estimate is not substituted for a native donation threshold. Financial ingestion remains independent of rule success. Simulation/replay defaults to no external action and no ordinary supporter totals.

Ko-fi speech uses Speaker.bot aliases, bounded templates and explicit privacy/language/moderation controls. The tested alias is `local english`. Bits sounds use validated local assets in the selected OBS overlay. Generic Streamer.bot actions use stable IDs and explicit allowlists; Streamer.bot remains the platform/action authority. VTube Studio-specific work is on hold.

Durable inbox/execution records prevent duplicate planning and distinguish rejection, failed/uncertain dispatch, acknowledged speech and browser playback completion. An acknowledgment is not proof of audible output. Uncertain external actions are not blindly repeated. Restored rules start disabled and stale queued work is suppressed.

Detailed contracts and qualified limitations are in [G09 automation](g09-automation.md). Release checks use explicitly opted-in owned examples in disposable data; [G10 qualification](g10-qualification.md) leaves actual paid-platform delivery unverified.
