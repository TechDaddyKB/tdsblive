# Glossary: words used in this guide

**Application data:** saved settings, layouts and other information. It is usually separate from the program files you downloaded.

**Asset:** an image, sound or video used by an overlay.

**Baseline:** the starting information a connection records so existing data is not mistaken for a new event.

**Browser Source:** an OBS source that displays a web page as part of your video.

**Canvas:** the rectangle where you arrange an overlay. Its dimensions are measured in pixels.

**Credential:** a password, token or private connection URL that gives access to a service.

**Desktop companion:** the small part of TDSBLive that shows its tray icon and desktop controls. The background application provides your chat and overlay pages.

**Dock:** a panel inside OBS that you use while working. It does not automatically appear in the broadcast.

**Event:** something the application receives, such as a new chat message or a supporter notification.

**Host:** the running TDSBLive application that provides the editor and overlay pages.

**HTTP:** the way your browser requests these local pages. Ordinary local use does not need an HTTPS certificate.

**LAN:** a local network, such as computers sharing your home router.

**Ledger:** the application's record of supporter events and amounts. It is not a bank or payout statement.

**Localhost / 127.0.0.1:** the computer you are currently using. On a second computer, the same address means that second computer.

**Minor units:** the smallest ordinary currency unit. For USD, 100 cents equals one dollar.

**Overlay:** a web page that OBS displays over your video. It can contain several widgets.

**Permission:** a specific ability you choose to grant, such as letting a widget receive chat or play audio.

**Port:** a numbered connection point used by an application. TDSBLive normally uses 17474; bot settings can use other ports.

**Prefix:** Wine or Proton's Windows-style folder containing a pretend C: drive, settings and saved data. A bottle is a managed Wine environment.

**Proton:** a Windows compatibility system for Linux, originally built for games. UMU can provide its runtime outside Steam.

**Revision:** an earlier saved state of a layout. It is different from a full application backup.

**Runner:** the Wine or Proton version used to start the Windows application.

**Sandbox:** a restricted environment that limits what custom widget code can access.

**Session-only:** a secret kept for the current run and cleared when the application restarts.

**Start at login:** an optional setting that starts TDSBLive when you sign in to Windows. It does not start an OBS broadcast.

**Token:** a secret value used to grant access. Treat a viewing link containing one as private.

**Tray / notification area:** the part of your desktop's taskbar or panel containing small icons for running applications. On Windows, some icons are inside the up-arrow menu beside the clock.

**WebSocket:** a connection that stays open so new messages can arrive without repeatedly requesting the whole page.

**Widget:** one item inside an overlay, such as text, chat, a goal or an alert box.

**Wine:** software that lets a Linux system run many Windows applications.

**ZIP:** a compressed collection of files. Extract the full collection before running an application from it.
